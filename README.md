# Enhao Cheng · Academic Homepage

Public website: https://chehaoa.github.io/

This repository hosts the standalone static export of Enhao Cheng's academic homepage. The HTML contains its stylesheet and image assets, so no server, external script, or build dependency is required.

The editable Jekyll source is maintained in the author's local homepage project. Rebuild and export the page after editing, then replace index.html here. Keep .nojekyll to serve the export directly.

Original template: [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io), MIT. The current page layout and SVG summaries were written for this homepage. Personal photograph supplied by the author; DCGC figure from the author's repository.
